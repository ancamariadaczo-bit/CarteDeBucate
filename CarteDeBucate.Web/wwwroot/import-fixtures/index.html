Recipe import fixtures

Use these pages as source URLs for manual recipe-import checks. They are deliberately static and do not require authentication.

Local-host note: the application deliberately rejects imports from localhost, loopback, and private-network addresses. You can browse these files locally, but end-to-end import requires this Web application to be reachable through a public HTTP/HTTPS address on port 80 or 443, such as a deployed test environment or a public tunnel.

JSON-LD fixtures

FixtureExpected result
json-ld-complete.htmlValid name, ingredients, and steps extracted from JSON-LD.
json-ld-missing-steps.htmlName and ingredients extracted; no steps. Show a non-blocking steps warning.
json-ld-missing-ingredients.htmlName and steps extracted; no ingredients. Saving should require user-entered ingredients.
json-ld-invalid-ingredients.htmlIngredients use blank and unsupported JSON values, so none are extracted. Saving should require user-entered ingredients.
json-ld-invalid-steps.htmlInstructions use blank and unsupported JSON values, so no steps are extracted. Saving remains allowed.
json-ld-invalid-name-html-fallback.htmlJSON-LD without a usable name falls back to visible HTML, which has no title. Saving should require a user-entered name.
json-ld-nested-instructions.htmlNested HowToSection/itemListElement instructions are extracted.
