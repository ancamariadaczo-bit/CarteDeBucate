# Architecture diagrams

These images are shown on the `Architecture` page in Plane. The page links to the files in this folder, so keep the file names.

- `system-overview`: the system from far away. Who uses it, where it runs, what it stores, which outside services it talks to.
- `inside-web-app`: the projects of the solution and the direction of dependencies.

The `.svg` file is the source. To change a diagram, edit the `.svg`, export a `.png` of the same name at twice the size, and update the image address on the Architecture page to the new commit.
