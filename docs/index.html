Privacy Policy for Recipe Clipper

Recipe Clipper accesses the content of the currently active web page only when the user explicitly activates the extension.

The extension processes website content in order to extract recipe information such as the recipe title, source URL, ingredients, preparation steps, and recipe image.

Data Processing

Recipe data is processed locally in the user's browser. Recipe Clipper does not send recipe data or website content to the developer, external servers, or third parties. All recipe extraction and processing is performed locally in the user's browser. Users may choose to print the extracted recipe or save it as a PDF on their own device.

Data Collection

Recipe Clipper does not collect personally identifiable information, authentication information, financial information, health information, location information, personal communications, or browsing history.

The extension does not track user activity or browsing behavior.

Data Sharing

Recipe Clipper does not sell, share, or transfer user data to third parties.

Local Processing and Export

Recipe information is processed locally in the user's browser. The extension may temporarily store recipe information locally when necessary to support its functionality. Users may choose to print an extracted recipe or save it as a PDF using the browser's print functionality. These actions are initiated by the user, and Recipe Clipper does not upload the resulting PDF or recipe data to the developer or to external servers.
