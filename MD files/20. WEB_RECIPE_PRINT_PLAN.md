# Plan 20 - Printarea retetelor salvate in Web

## Scop

Adauga actiunea `Printeaza` in lista de retete si in pagina Details. Actiunea deschide intr-un tab nou o pagina dedicata, apoi afiseaza automat dialogul de printare al browserului.

Pagina printabila foloseste stilul extensiei Chrome si afiseaza:

- numele retetei;
- `Source`;
- `Ingredients`;
- `Instructions`;
- coloana rezervata imaginii, cu mesajul `Image unavailable`.

## Limite stabilite

- Nu adauga imaginea sau URL-ul imaginii in aceasta implementare.
- Nu modifica modelele Core, repository-urile, schema SQLite, backup-ul, API-ul sau extensia Chrome.
- Cand suportul foto va fi integrat in Web, pagina de print va afisa imaginea salvata, URL-ul imaginii si mesajul de fallback daca imaginea nu poate fi afisata.
- Nu include notitele sau alte campuri care nu au fost cerute.

## Regula de lucru

Executa un singur pas mic, arata fisierele modificate si verificarile relevante, apoi opreste-te si asteapta aprobarea utilizatorului. Nu incepe automat pasul urmator.

## Pasul 1 - Adauga actiunea Print

In `RecipesController`, adauga o actiune GET care incarca reteta prin `IRecipeLibraryService`, pastreaza filtrarea utilizatorului curent si foloseste acelasi rezultat 404 ca Details pentru o reteta inexistenta sau inaccesibila.

Adauga teste de controller pentru reteta gasita si reteta inexistenta.

Opreste-te si asteapta aprobarea.

## Pasul 2 - Adauga structura paginii printabile

Creeaza view-ul dedicat pentru print, fara layout-ul Web obisnuit. Randeaza continutul ca text Razor sigur, cu titlul retetei, linkul `Source`, lista `Ingredients`, lista `Instructions` si coloana din dreapta cu `Image unavailable`.

Opreste-te si asteapta aprobarea.

## Pasul 3 - Adauga stilurile de print

Creeaza un stylesheet dedicat, adaptat din `CarteDeBucate.ChromeExtension/print.css`: pagina A4, doua coloane in partea de sus, spatiu rezervat imaginii, instructiunile sub cele doua coloane si reguli pentru evitarea ruperilor nepotrivite intre pagini.

Opreste-te si asteapta aprobarea.

## Pasul 4 - Deschide automat dialogul de print

Adauga un script dedicat care apeleaza `window.print()` dupa incarcarea paginii. Nu inchide automat tabul daca utilizatorul imprima sau anuleaza dialogul.

Opreste-te si asteapta aprobarea.

## Pasul 5 - Adauga butoanele Printeaza

Adauga butonul `Printeaza` langa `Editeaza` si `Sterge` in:

- `Views/Recipes/Index.cshtml`;
- `Views/Recipes/Details.cshtml`.

Ambele linkuri deschid pagina Print intr-un tab nou si nu pierd starea listei sau a paginii Details.

Opreste-te si asteapta aprobarea.

## Pasul 6 - Verificare finala

Verifica testele Web relevante si confirma manual:

1. butonul exista in lista si in Details;
2. pagina se deschide intr-un tab nou;
3. dialogul de print apare automat;
4. continutul si titlurile in engleza sunt corecte;
5. coloana `Image unavailable` ramane rezervata;
6. URL-urile lungi si retetele lungi se imprima fara overflow;
7. o reteta inexistenta sau a altui utilizator nu poate fi printata.

Opreste-te si raporteaza rezultatele.
