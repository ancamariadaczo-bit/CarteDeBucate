# Implementare Web pentru export/import backup JSON

## Context observat in cod

### Export JSON in aplicatia desktop

- Meniul desktop are optiuni separate pentru backup JSON:
  - `MainMenuOption.ExportBackup` in `CarteDeBucate.App/ConsoleUI/RichConsole/RichConsoleRecipeApp.cs`
  - `MenuKeys.ExportBackup` in `CarteDeBucate.App/ConsoleUI/ClassicConsole/ClassicConsoleRecipeApp.cs`
- Flow-ul rich console:
  1. afiseaza mesajul `AppTexts.EnterExportBackupFilePath`;
  2. citeste calea fisierului cu `_reader.ReadBackupFilePath()`;
  3. daca path-ul este gol, revine fara actiune;
  4. apeleaza `_backupService.ExportToJson(backupFilePath)`;
  5. afiseaza `RecipeBackupResult.Message` ca succes sau eroare.
- Flow-ul classic console face acelasi lucru, doar ca afiseaza direct mesajul rezultat.
- Logica reala este in `RecipeBackupService.ExportToJson(string backupFilePath)`:
  1. valideaza path-ul si directorul;
  2. ia retetele din contextul curent:
     - `GetRecipesByUserId(CurrentUserId.Value)` daca exista user curent;
     - `GetAllRecipes()` daca nu exista user curent;
  3. serializeaza `List<Recipe>` cu `System.Text.Json`, `WriteIndented = true`;
  4. scrie fisierul cu `File.WriteAllText`;
  5. intoarce `RecipeBackupResult` cu `ExportedCount` si mesajul `BackupExportCompleted`.

### Import JSON in aplicatia desktop

- Meniul desktop are optiuni separate pentru import backup JSON:
  - `MainMenuOption.ImportBackup` in rich console;
  - `MenuKeys.ImportBackup` in classic console.
- Flow-ul rich console:
  1. afiseaza `AppTexts.EnterImportBackupFilePath`;
  2. citeste calea fisierului cu `_reader.ReadBackupFilePath()`;
  3. daca path-ul este gol, revine fara actiune;
  4. apeleaza `_backupService.ImportFromJson(backupFilePath)`;
  5. afiseaza `RecipeBackupResult.Message` ca succes sau eroare.
- Logica reala este in `RecipeBackupService.ImportFromJson(string backupFilePath)`:
  1. verifica daca fisierul exista;
  2. citeste continutul cu `File.ReadAllText`;
  3. deserializeaza `List<Recipe>`;
  4. daca lista este invalida, intoarce `InvalidBackupFile`;
  5. pentru fiecare reteta:
     - verifica duplicat dupa `SourceUrl`;
     - verifica duplicatul in contextul userului curent daca exista `CurrentUserId`;
     - ignora retetele duplicate si creste `SkippedCount`;
     - reseteaza `recipe.Id = 0`;
     - seteaza `recipe.UserId = CurrentUserId.Value` daca exista user curent;
     - salveaza reteta cu `_recipeRepository.AddRecipe(recipe)`;
  6. intoarce `RecipeBackupResult` cu `ImportedCount`, `SkippedCount` si mesajul `BackupImportCompleted`.

### Starea aplicatiei Web

- `CarteDeBucate.Web/Program.cs` inregistreaza deja `IRecipeBackupService` in DI.
- Web-ul are deja import din URL in `RecipesController.Import`, dar nu are inca rute/view-uri pentru backup JSON.
- Layout-ul are navigatie pentru:
  - lista de retete;
  - adaugare reteta;
  - import din URL.
- Cel mai mic traseu pentru Web este sa adaugam un controller separat pentru backup JSON, ca sa nu amestecam feature-ul de backup cu importul din URL.

## Decizie de implementare propusa

Folosim un controller Web separat, de exemplu `RecipeBackupsController`, care primeste `IRecipeBackupService`.

Pentru Web nu folosim fisiere temporare. In schimb, adaugam metode noi in Core care lucreaza direct cu continut JSON:

- export Web:
  - controller-ul apeleaza o metoda noua din Core, de exemplu `ExportToJsonContent()`;
  - metoda noua returneaza rezultatul exportului impreuna cu textul JSON;
  - controller-ul transforma textul JSON in bytes UTF-8;
  - controller-ul intoarce `File(bytes, "application/json", "recipes-backup-YYYYMMDD-HHMMSS.json")`;
- import Web:
  - userul incarca un fisier `.json` prin `IFormFile`;
  - controller-ul citeste continutul upload-ului ca text;
  - controller-ul apeleaza o metoda noua din Core, de exemplu `ImportFromJsonContent(json)`;
  - metoda noua deserializeaza si importa retetele folosind aceleasi reguli ca importul desktop.

Metodele existente raman disponibile pentru desktop:

- `ExportToJson(string backupFilePath)`;
- `ImportFromJson(string backupFilePath)`.

Implementarea lor poate fi pastrata temporar sau poate delega catre metodele noi:

- `ExportToJson(path)` valideaza path-ul, apeleaza `ExportToJsonContent()`, apoi scrie continutul in fisier;
- `ImportFromJson(path)` verifica fisierul, citeste continutul, apoi apeleaza `ImportFromJsonContent(json)`.

Avantaj: Web-ul nu depinde de fisiere temporare, iar Core incepe sa aiba o separare mai clara intre logica de backup si detaliul "de unde vine/unde se duce JSON-ul". In viitor, metodele pentru app si Web pot fi unificate complet in jurul metodelor content/stream.

Scop: facem Core reutilizabil pentru Web fara fisiere temporare.

- Extinde `IRecipeBackupService` cu metode noi, de exemplu:
  - `RecipeBackupExportResult ExportToJsonContent();`
  - `RecipeBackupResult ImportFromJsonContent(string json);`
- Creeaza model nou in Core, de exemplu `RecipeBackupExportResult`, cu:
  - `bool IsSuccess`;
  - `string Message`;
  - `int ExportedCount`;

## Riscuri si detalii de urmarit

- `RecipeBackupService` lucreaza acum cu path-uri de fisiere; pentru Web trebuie adaugate metode content ca sa evitam fisiere temporare.
- Metodele vechi pe path trebuie sa ramana compatibile cu desktop-ul.
- Exportul Web trebuie sa foloseasca bytes UTF-8 din JSON-ul returnat de Core.
- Importul Web trebuie sa citeasca upload-ul ca text si sa lase Core sa faca deserializarea si regulile de import.
- Nu trebuie schimbata serializarea existenta: `List<Recipe>` cu `WriteIndented = true`.
- Nu trebuie schimbata regula de import:
  - duplicat dupa `SourceUrl`;
  - `Id = 0` inainte de salvare;
  - `UserId` setat din contextul curent cand exista.
- Daca se adauga `ErrorMessage` in layout, trebuie pastrat `SuccessMessage`, fiindca este folosit deja de flow-urile existente.
- Nu amesteca importul din URL cu importul backup JSON; sunt doua feature-uri diferite.

## Definitia de done

- Exista pagina Web `Backup JSON`.
- Exportul descarca un fisier JSON valid cu retetele din contextul curent.
- Importul accepta upload de fisier JSON.
- Importul afiseaza cate retete au fost importate si cate au fost ignorate.
- Importul gestioneaza fisier lipsa, fisier invalid si esecuri din serviciu.
- Flow-ul desktop ramane neschimbat.
- Testele dedicate pentru controller-ul de backup trec.
- Build-ul Web trece.
