# Plan separare RecipeImporterService

## Scop

Separarea responsabilitatilor din `RecipeImporterService` inainte de implementarea paginarii.

La final:

- `RecipeImporterService` ramane responsabil pentru importul din link.
- un serviciu nou, propus `RecipeLibraryService`, devine responsabil pentru retele salvate: listare, cautare, citire detalii, salvare manuala, editare si stergere.
- planul de paginare ramane neschimbat in `MD files/7. PAGINARE_RETETE_PLAN.md`; dupa acest refactor, paginarea se va implementa peste serviciul nou.

## De ce `RecipeLibraryService`

Numele `RecipeLibraryService` descrie mai bine ce face serviciul nou: lucreaza cu biblioteca de retete salvate.

Nu il numim `RecipeDatabaseService`, pentru ca aplicatia inca suporta doua surse prin `IRecipeRepository`:

- SQLite database;
- JSON file.

Serviciul nou nu ar trebui sa stie detalii despre storage. El trebuie sa foloseasca `IRecipeRepository`, exact cum face acum `RecipeImporterService`.

## Reguli de lucru

- Nu schimba comportamentul vizibil in acest refactor.
- Nu schimba inca paginarea.
- Nu modifica `MD files/7. PAGINARE_RETETE_PLAN.md`.
- Nu schimba contractul `IRecipeRepository`.
- Nu muta logica in controllere sau in UI.
- Pastreaza filtrarea pe `CurrentUserId`.
- Pastreaza `RecipeSummary` pentru listare si search.
- Pastreaza cautarea existenta in nume, URL, notite, ingrediente si pasi.
- Pastreaza mesajele existente din `AppTexts`.
- Fa fiecare pas mic si opreste-te pentru review dupa fiecare pas.

## Starea curenta

`CarteDeBucate.Core/Services/IRecipeImporterService.cs` contine acum metode din doua zone diferite.

Zona de import:

- `ImportRecipeFromUrlAsync(string url)`
- `ImportFromUrlAndSaveAsync(string url)`

Zona de biblioteca retete salvate:

- `GetRecipeSummaries()`
- `HasRecipesInCurrentContext()`
- `GetRecipeById(int recipeId)`
- `SearchRecipes(string searchText)`
- `SaveRecipe(Recipe recipe)`
- `UpdateRecipe(Recipe recipe)`
- `DeleteRecipe(int recipeId)`

`CarteDeBucate.Core/Services/RecipeImporterService.cs` foloseste acum:

- `IRecipeImporter`, pentru import din URL;
- `IRecipeRepository`, pentru citire/scriere retete salvate;
- `ICurrentUserContext`, pentru filtrare pe user.

## Structura tinta

### `IRecipeLibraryService`

Fisier nou propus:

- `CarteDeBucate.Core/Services/IRecipeLibraryService.cs`

Responsabilitati:

- listare retete salvate;
- verificare daca exista retete in contextul curent;
- citire reteta dupa id;
- cautare retete;
- salvare reteta;
- update reteta;
- stergere reteta.

Metode propuse initial:

```csharp
public interface IRecipeLibraryService
{
    List<RecipeSummary> GetRecipeSummaries();

    bool HasRecipesInCurrentContext();

    Recipe? GetRecipeById(int recipeId);

    List<RecipeSummary> SearchRecipes(string searchText);

    RecipeSaveResult SaveRecipe(Recipe recipe);

    RecipeSaveResult UpdateRecipe(Recipe recipe);

    RecipeSaveResult DeleteRecipe(int recipeId);
}
```

### `RecipeLibraryService`

Fisier nou propus:

- `CarteDeBucate.Core/Services/RecipeLibraryService.cs`

Dependinte:

- `IRecipeRepository`
- `ICurrentUserContext?`

Nu depinde de:

- `IRecipeImporter`

### `IRecipeImporterService`

La final, ramane doar cu importul din URL:

```csharp
public interface IRecipeImporterService
{
    Task<RecipeImportResult> ImportRecipeFromUrlAsync(string url);

    Task<RecipeSaveResult> ImportFromUrlAndSaveAsync(string url);
}
```

### `RecipeImporterService`

La final, depinde de:

- `IRecipeImporter`
- `IRecipeLibraryService`

Nu mai depinde direct de:

- `IRecipeRepository`
- `ICurrentUserContext`

`ImportFromUrlAndSaveAsync` importa reteta, apoi apeleaza `IRecipeLibraryService.SaveRecipe(importResult.Recipe)`.

## Comenzi utile de verificare

Build:

```bash
dotnet build CarteDeBucate.slnx
```

Teste:

```bash
dotnet test CarteDeBucate.slnx
```

Cautare folosiri importer:

```bash
rg -n "IRecipeImporterService|RecipeImporterService|_importerService\\.|_recipeService\\." CarteDeBucate.Core CarteDeBucate.App CarteDeBucate.Web CarteDeBucate.Tests
```

Cautare folosiri library:

```bash
rg -n "IRecipeLibraryService|RecipeLibraryService|_recipeLibraryService\\." CarteDeBucate.Core CarteDeBucate.App CarteDeBucate.Web CarteDeBucate.Tests
```
